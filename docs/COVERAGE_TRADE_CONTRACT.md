# Constellation coverage-trade contract

Coverage is meaningful only with a stated target regime, geography, time window, and confidence requirement. The trade contract binds those definitions to node count, duty cycle, node availability, orbital assumptions, instrument assumptions, model identity, coverage fraction, and uncertainty.

No coverage model or capability figure is included. The fixture proves contract behavior only. A real model requires independently reviewed orbital, sensor, environmental, failure, and latency assumptions before any demonstrator or constellation conclusion.

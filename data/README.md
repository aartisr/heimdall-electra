# Local evidence cache

This directory contains locally archived raw artifacts and manifests retrieved through approved Heimdall source connectors.

Current content: the NOAA SWPC planetary K-index feed, stored under external/noaa-swpc as content-addressed bytes plus an append-only acquisition manifest.

The archive is external geomagnetic context only. It is not observed Heimdall debris evidence, does not validate the proposed physics, and must not be used as a debris label or candidate-promotion input.
